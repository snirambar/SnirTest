MWC Barcelona Attendee Scraper

Scrape attendees by bucket and country, export to CSV

How to get your JWT Token:
  1. Go to mwcbarcelona.com/mymwc/search
  2. Open DevTools (F12 or Cmd+Option+I)
  3. Go to Network tab
  4. Apply any filter on the page
  5. Click the search request → Headers
  6. Copy the Jemex-Authorization value
